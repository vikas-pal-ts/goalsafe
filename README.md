Planned structure:
```
goalsafe/
├── frontend/
└── backend/
```

Future frontend:
Next.js / React

Future backend:
Python API

The benchmark repository remains separate.
Datasets are located in the benchmark repository and must NOT be copied into `goalsafe/`.
